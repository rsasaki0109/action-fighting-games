# MMA Fighter

2D対戦格闘ゲーム (Player vs CPU)

![Gameplay](gameplay.gif)

## Play

https://rsasaki0109.github.io/mma_fight/

## Controls

| Key | Action |
|-----|--------|
| ← → | Move |
| A | Jab (fast, low damage) |
| S | Low Kick (slows enemy) |
| D | Heavy (high damage, slow) |
| Shift | Guard |

## Rules

- 60 seconds, 1 round
- HP: 100 / Stamina: 100
- KO or time up decides winner
