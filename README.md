# Internet Meme All-Stars

2D横対戦アクションゲーム（スマブラ風）

## Play

https://rsasaki0109.github.io/internet_meme_allstars/

## Features

- スマホブラウザで2人対戦（1端末共有）
- タップ操作で簡単プレイ
- 3ストック制バトル

## Characters

| キャラ | 特徴 |
|--------|------|
| Doge | 高速移動、30%で即死級ノックバック |
| Trollface | 高火力、攻撃命中で操作反転 |

## Controls

画面を左右に分割、各プレイヤーが自分のエリアで操作

```
┌─────────────────┬─────────────────┐
│   [←] [↑] [→]   │   [←] [↑] [→]   │
│    [ATTACK]     │    [ATTACK]     │
│    Player 1     │    Player 2     │
└─────────────────┴─────────────────┘
```
