# Internet Meme All-Stars

2D横対戦アクションゲーム

![Battle](assets/battle_enhanced.gif)

## Play

https://rsasaki0109.github.io/internet_meme_allstars/

## Game Modes

- **1P vs CPU** - CPUと対戦（難易度: Easy / Normal / Hard）
- **2P vs 2P** - 1端末で2人対戦

## Characters

| キャラ | 特徴 |
|--------|------|
| Doge | 高速移動・二段ジャンプ・30%即死 |
| Trollface | 高火力・スーパーアーマー・操作反転 |
| Pepe | 遠距離攻撃（涙弾） |
| Wojak | カウンター技 |
| Nyan Cat | 三段ジャンプ・虹エフェクト |
